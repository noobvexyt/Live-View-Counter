Live View Counter

Site owner

For the person who runs this site: switch on YouTube for everyone, and deal with reports. This is separate from your own account and page on the site.

Owner sign-in

The ADMIN_PASSWORD you chose in Vercel (your project → Settings → Environment Variables). Signing in stores one cookie for up to 12 hours.

Set up the site

1Switch on YouTube

The site reads everyone’s channel numbers with one YouTube API key: yours. It’s free from Google and takes about 3 minutes to get.

Checking…

It’s checked with Google first (using 1 of the key’s 10,000 free daily units), then kept in the site’s private database. It’s never shown on any page.

How to get a free YouTube API key
  1. Open Google Cloud: new project and sign in with your Google account. Name the project Live View Counter website and click Create.
  2. Open YouTube Data API v3. Check your new project is selected at the top of the page, then click Enable.
  3. Open Credentials, click + Create credentials and choose API key. Copy the key.
  4. Recommended: open the key’s settings. Under API restrictions choose Restrict key, tick YouTube Data API v3 and click Save. Leave Application restrictions set to None, because the site’s server uses the key, not people’s browsers.
  5. Paste the key in the box above and click Check and save.

No card or billing needed. Use a new key just for this website, not the one the counter on your computer uses, so they don’t share one daily allowance. Each 10,000-unit day covers up to about 300 channels being watched at once.

2Make your own page

Your own counter page uses a normal account on the site, not these owner tools. Sign up (or sign in), then type your channel’s @handle on the page you get.

You’re signed in as . Open your page to add your channel. It stays private until you make it public on your account page.
