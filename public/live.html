How to get your free API key (about 3 minutes)
  1. Open Google Cloud: new project and sign in with your Google account. Name the project Live View Counter and click Create.
  2. Open YouTube Data API v3. Make sure your new project is selected at the top of the page, then click Enable.
  3. Open Credentials, click + Create credentials and choose API key. Copy the key and paste it above.
  4. Recommended: open the key’s settings. Under API restrictions choose Restrict key, tick YouTube Data API v3 and click Save. Leave Application restrictions set to None.

No billing or card needed. Google gives every project a free daily allowance, and the counter paces itself to stay inside it, even if you leave it running all day.

    How to get an Instagram token (about 10 minutes)
    1. Your Instagram account has to be a free professional account (Creator or Business). In the Instagram app: Settings → Account type and tools → Switch to professional account.
    2. Open Meta for Developers, log in, and click Create app. Choose the use case for Instagram (Manage messaging & content on Instagram) and finish creating the app.
    3. In your new app, open Instagram → API setup with Instagram login. Under Generate access tokens, click Add account and sign in to your Instagram account.
    4. Click Generate token next to your account, copy the token and paste it above.
